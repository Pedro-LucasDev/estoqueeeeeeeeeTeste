# 📦 StockFlow

> Sistema web para gerenciamento e controle de estoque.

## 📌 Sobre o projeto

O **StockFlow** é um sistema desenvolvido para facilitar o **gerenciamento de produtos e controle de estoque**, permitindo organizar informações de forma simples, intuitiva e eficiente.

O projeto foi desenvolvido como uma aplicação prática para colocar em uso conhecimentos de **desenvolvimento web, lógica de programação e gerenciamento de dados**.

## 🎯 Objetivo

O objetivo do StockFlow é oferecer uma solução simples para:

* Cadastrar produtos
* Visualizar produtos cadastrados
* Editar informações
* Excluir produtos
* Organizar o estoque
* Facilitar o acompanhamento dos produtos

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — estilização e responsividade
* **JavaScript** — lógica e interatividade
* **SQL** — gerenciamento e manipulação de dados

## ⚙️ Funcionalidades

### 📦 Gerenciamento de produtos

O sistema permite realizar operações básicas sobre os produtos:

* ➕ Adicionar novos produtos
* 👁️ Visualizar produtos

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone SEU-LINK-DO-GITHUB
```

2. Entre na pasta do projeto:

```bash
cd StockFlow
```

3. Abra o arquivo `index.html` no navegador.

> 💡 Caso esteja utilizando o Visual Studio Code, também é possível executar o projeto utilizando a extensão **Live Server**.
